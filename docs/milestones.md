# Milestones and Deliverables – EduNexus

This list is aligned with the official project definition and plan.

## Milestone 1 – Literature Review and Requirements

- Complete literature review on AI in education, adaptive learning, and gamification.
- Produce `literature_review_notes.md`.
- Conduct initial user research (interviews / questionnaires).
- Produce `requirements.md` with functional and non-functional requirements.

## Milestone 2 – Architecture and Database Schema

- Finalise high-level system architecture.
- Design database schema (entities and relationships).
- Document architecture in `system_architecture.md` and `data_model.md`.

## Milestone 3 – MVP: Core Classroom and AI Lesson Generation

- Implement FastAPI backend skeleton and core models.
- Implement basic Next.js frontend with teacher and student dashboards.
- Integrate AI lesson generation from teacher prompts.
- Demonstrate end-to-end flow:
  - Teacher → prompt → AI lesson → published lesson → student views it.

## Milestone 4 – Adaptive Learning and Gamification

- Implement adaptive quiz logic in the backend.
- Implement XP, badges, and leaderboards.
- Update frontend to support adaptive quizzes and gamification UI.

## Milestone 5 – Dashboards, Analytics, and Accessibility

- Implement teacher and student analytics dashboards.
- Improve responsiveness and accessibility of the UI.
- Add basic multilingual and text-to-speech support or stubs.

## Milestone 6 – Evaluation, LMS Integration, and Final Report

- Conduct user testing with teachers and students.
- Collect usage data and feedback.
- Analyse results against research questions.
- Implement a minimal LMS integration (e.g. SCORM-related data export or design).
- Complete final project report and prepare demo.
